## Design editor

Edit colors, typography, spacing, logos, and avatars in the browser. Choose from three palette presets or import and export design tokens as JSON. Shared validation keeps the preview and generated CSS consistent.

## GitHub integration

Save a configuration through GitHub sign-in, then create a fork with the settings and artwork applied in one commit. Existing repositories are protected from overwrites. Import the fork into Vercel to deploy it.

## Included

English, Spanish, and Italian pages, light and dark themes, PWA support, and generated favicons, app icons, and social images. Built with Next.js, React, TypeScript, and Tailwind CSS; interaction tests use Playwright.
