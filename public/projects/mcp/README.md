# Connect

One connector for the platform’s apps. Discover capabilities, check requests, and act through MCP, REST, or live events under the same policy.

[Open Connect](https://connect.montymi.com)

## What it does

Connect is the Charon gateway. Its root is a landing page for people; `/mcp` is the assistant connector, `/rest/v1` is the HTTP API, and `/rest/v1/ws` carries live events.

To add a Claude custom connector, use:

```text
https://connect.montymi.com/mcp
```

## Source

Connect is implemented in the `montymi/mcp` repository. It does not declare a package release version, so the project records its source revision.

This is the public project overview. The [source repository](https://github.com/montymi/mcp) is private and requires GitHub access. The Started date records the earliest source history date, not a tagged release.
