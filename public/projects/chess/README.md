# Chess

Play against a hand-built AI or a friend online, then explore your games, mistakes, and openings. Available to assistants through Connect.

[Open Chess](https://chess.montymi.com)

## What it does

Play against a hand-built chess engine or a friend online. Review games and explore mistakes and openings through the question language. Assistants use the shared Connect gateway.

## Source

The frontend package declares version 0.1.0. The repository includes the game interface, backend engine, and tests.

This is the public project overview. The [source repository](https://github.com/montymi/chess) is private and requires GitHub access. The Started date records the earliest source history date, not a tagged release.
