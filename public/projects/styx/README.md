# Styx

The platform’s identity layer: sign-in, OAuth / OIDC, and roles, with an independent identity authority for each operator.

[Open Styx](https://styx.montymi.com)

## What it does

Styx is the platform’s identity layer, built on ZITADEL. It provides sign-in, OAuth / OIDC, and roles. Each independent operator can run their own identity authority.

## Source

Styx is part of the Charon repository, not a separate application repository. This project records the Styx integration’s source revision; the underlying ZITADEL version is a separate dependency.

This is the public project overview. The [source repository](https://github.com/montymi/charon/tree/main/styx) is private and requires GitHub access. The Started date records the earliest source history date, not a tagged release.
